# 🧾 Générateur de Factures

Une application web simple, moderne et intuitive permettant de créer des factures professionnelles au format PDF directement depuis un navigateur.

## ✨ Fonctionnalités

- 👤 Saisie du nom du client.
- 📦 Ajout d'articles à la facture.
- 🔢 Gestion des quantités et des prix unitaires.
- 🧮 Calcul automatique des totaux.
- ✏️ Modification des articles.
- 🗑️ Suppression des articles.
- 📄 Génération et téléchargement des factures en PDF.
- 🏢 Personnalisation des informations de l'entreprise.
- 🖼️ Ajout et suppression du logo de l'entreprise.
- 📱 Interface responsive adaptée aux écrans mobiles.
- 🌙 Prise en charge du thème clair et sombre.
- 💾 Sauvegarde des informations de l'entreprise dans le navigateur.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- jsPDF (génération des documents PDF)
- LocalStorage (sauvegarde locale des informations)

## 🚀 Installation et utilisation

Aucune installation de Python ou de bibliothèques supplémentaires n'est nécessaire.

1. Téléchargez le projet.
2. Ouvrez le dossier.
3. Double-cliquez sur `facture.html`.
4. L'application s'ouvre dans votre navigateur.
5. Commencez à créer vos factures !


## 📄 Génération PDF

Les factures générées peuvent contenir :

- Les informations du client.
- Les informations de l'entreprise.
- Le logo de l'entreprise.
- La date de facturation.
- La liste des articles.
- Les quantités et prix unitaires.
- Le montant total à payer en DA.

## 💡 Personnalisation

Dans l'onglet « Informations de l'entreprise », vous pouvez renseigner :

- Le nom de votre entreprise.
- Le numéro de téléphone.
- L'adresse e-mail.
- L'adresse professionnelle.
- Le logo de votre entreprise.

Les informations sont sauvegardées localement dans le navigateur.
